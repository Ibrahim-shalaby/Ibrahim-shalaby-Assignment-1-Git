git squash 
هو دمج اكتر من كومت في كومت واحد وبنسخدمه نخلي تاريخ الكومت نظيف
 ولو فيه برانش شغاليت عليه بعمل سكواش قبل مندمج التغيرات
 --------------------------------------------------
git merge vs git rebase
git merge
بتدمج الفرعين مع بعض وتنشا كومت جديد مع المحافظة علي السجل كامل 
git rebase 
بتنقل الكومتات الي موجود في الفرع الي فرع خر  وبيبقوا في لين واحد
 -------------------------------------------------
 
 git help
بنستخدمه لما نكون مش فاكرين نستخدم أمر معين 
او لو عايزين نعرف تفاصيل عنه وايه الوظائف الي بيعملها
 --------------------------------------------------
 git cherry-pick
 لو عايز تاخد كمت من برانش تاني وعايز تحطه عندك
 ------------------------------------------------
 git clean 
  بينظف المشروع من الملفات الي مش معملوها ان تراكد
  --------------------------------------------------
git grep
تستخدم للبحث عن الكلمات أو الأكواد داخل مشروع
 -------------------------------------------------------
 git blame
 تستخدم لمعرف من عمل هذا التعديل في هذا السطره وامتي
 git bisect
 هي اداه سريعة وذكية في جيت تستخدك لمعرف الكمت الذي تسبب في مشكله
 -----------------------------------------------------
 git shortlog
 يجمع لك الكمتات الي عملها شخص
 -----------------------------------------------------
 git prune
 يعني هو بيمسح الحاجه الي اتحذفت ولسه محفوظه بمسح البيانات نهائي
 -----------------------------------------------------
git worktree
يعني بدل ما كنا بعمل جيت استاش علشان اروح  اعمل تغيرات في فرع تاني 
هي دلوقت بتفتح مجلد جنبك علشان تعمل التغيرات دي
 ---------------------------------------------------
 git verify-commit
 بتتحقق من التوقيع الرقمي للكمت لضمان انه جاي من صاحبه 
 ومش مزور
 ---------------------------------------------------
 git filter-repo
 تخدم لتعديل وإعادة كتابة تاريخ مثل حذف بيانات سريةاو ملفات كبيرة
